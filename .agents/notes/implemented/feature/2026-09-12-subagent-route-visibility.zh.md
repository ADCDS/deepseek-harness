# Agent Note: 子智能体路由可见性

Status: implemented

[English](2026-09-12-subagent-route-visibility.md) | 中文

## Problem

用户无法从子会话目录行、输入区域或父会话的委派卡片识别所用的提供商和模型。后端默认值和每次调用的覆盖值可能与父会话路由不同。

## Decision

子会话目录行和只读输入区域显示由已记录请求头派生的 `modelSelection.lastUsed`。子会话模型控件读取同一投影，目录可用时显示名称，否则显示原始 ID。子会话可以加载共享目录，但仍不能切换模型或使用模型命令。

委派工具立即返回托管子会话 ID。可选的规范 `route` 依次使用显式子会话选项、后端默认路由，以及后端允许继承时的父会话值。完整路由未知的外部后端省略此字段。展示元数据将该路由传递给父会话卡片，不改变模型可见的结果文本。可选输出字段进入 PTC 工具模式。

## Alternatives considered

增加持久化子智能体描述符会重复请求头，并描述请求的路由而非后续请求。每次从子投影派生父会话卡片会让历史展示依赖该投影继续存在。规范工具元数据保留激活开始时已知的路由。

## Consequences

未知路由不显示。分叉历史最初可能包含继承的父会话请求头；子会话记录自己的请求后，显示随之更新。测试覆盖后端默认值、覆盖值、未知外部后端、目录不可用、拒绝子会话模型切换、格式错误的元数据，以及当前原生和 PTC 会话回放。历史 Session 代次保持不变。

[委派包](../../../../packages/subagent/tool-subagent/README.zh.md)负责路由选择；本决策负责其展示。
